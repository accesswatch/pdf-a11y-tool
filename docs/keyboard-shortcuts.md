# Keyboard Shortcuts Reference

## File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | Create a new blank tagged PDF |
| `Ctrl+O` | Open an existing PDF file |
| `Ctrl+S` | Save the current file |
| `Ctrl+Shift+S` | Save as a new file |
| `Alt+F4` | Exit the application |

## Edit Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo the last action |
| `Ctrl+Y` | Redo the last undone action |

## View Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+=` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Fit page to window (100%) |
| `Ctrl+Shift+O` | Toggle reading order overlay on page view |
| `Ctrl+Shift+R` | Switch to the Screen Reader Preview panel |

## Accessibility Check

| Shortcut | Action |
|----------|--------|
| `F5` | Run full accessibility check |

## Tag Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+Alt+A` | Set alt text on selected element |
| `Ctrl+Alt+L` | Set language on selected element |

## Navigation

| Shortcut | Action |
|----------|--------|
| `F6` | Cycle focus through main panels |
| `Ctrl+Tab` | Cycle through bottom tab panels (Issues, Fields, Alt Text, Tables, SR Preview) |
| `Arrow Keys` | Navigate the tag tree or lists |
| `F2` | Rename selected tag (in tag tree) |
| `Alt+Up` | Move selected item up (reading order, fields list) |
| `Alt+Down` | Move selected item down (reading order, fields list) |

## Help

| Shortcut | Action |
|----------|--------|
| `Ctrl+/` | Show keyboard shortcuts dialog |
